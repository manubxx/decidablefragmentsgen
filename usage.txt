USAGE:
 ./DecidableFragmentsGen <options>

BASIC OPTIONS:
  --fragment <name>        Logical fragment (default: fo2)
                             fo2      = Two-Variable Fragment
                             fluted   = Fluted Fragment
                             guarded  = Guarded Fragment
                             unaryneg = Unary Negation Fragment
                             modal    = Modal Logic Fragment
  --mode <mode>            Generation mode (default: free)
                             free     = random formulas
                             sat      = satisfiable formulas
                             unsat    = unsatisfiable formulas
                             satbuild = construction of satisfiable formulas (only FO2)

  --domain-size            Finite model size, 2^n (only satbuild)            
  --depth <n>              Max syntactic tree depth (default: 3)
  --count <n>              Number of formulas to generate (default: 5)
  --seed <n>               Seed for reproducibility (default: random)
  --help                   Show this message and exit

TESTING & DATASETS OPTIONS:
  --run-benchmarks <path>  Run the (CASC) test on .p files in a specified folder
  --generate-datasets      Start massive dataset generation for the chosen fragment
  --run-timeout-analysis   Run a timeout calibration analysis on discarded formulas


FORMULA STRUCTURE OPTIONS:
  --and <n|min:max>        AND nodes: exact count or range 
  --or <n|min:max>         OR nodes
  --not <n|min:max>        NOT nodes
  --exists <n|min:max>     EXISTS quantifiers
  --forall <n|min:max>     FORALL quantifiers
  --implies <n|min:max>    IMPLIES connectives
  --eq <n|min:max>         Equality atoms =
                             In FL allowed only with stackDepth >= 2.

VOCABULARY OPTIONS:
  --preds <count>/<arity>                                
                           Specify the vocabulary explicitly.
                           Example:
                             --preds 3/1,2/2      (3 unary + 2 binary)
                           In FO2 the max arity is 2.
                           In FL the arity is arbitrary (k >= 1).
                           If omitted, the default vocabulary is used.
  --arity <k|mixed>        Filter vocabulary predicates by arity.
                             mixed = all (default)
                             k     = only predicates of arity k

TRANSFORMATION OPTIONS:
  --transform <mode>       (default: none)
                             none = no transformation
                             nnf  = Negation Normal Form

OUTPUT OPTIONS:
  --output <format>        (default: default)
                             default = internal readable format
                             tptp    = TPTP format


VERIFICATION OPTIONS (Vampire):
  --verify                 Verify each formula with Vampire.
  --vampire-path <path>    Path to the Vampire executable (default: vampire).
  --vampire-timeout <n>    Timeout in seconds (default: 10).

EXAMPLES:
  ./DecidableFragmentsGen --fragment fo2 --mode sat --depth 3 --count 5 --domain-size 3
  ./DecidableFragmentsGen --fragment fluted --mode sat --depth 4 --domain-size 3
  ./DecidableFragmentsGen --fragment fo2 --mode sat --depth 3 --domain-size 3 --verify
